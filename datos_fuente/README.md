# Informe: Datos Fuente
En esta carpeta se encuentran los archivos originales que contienen la información cruda del proyecto de turismo.

## Contenido:
- **ACTIVIDAD.csv / .xlsx**: Datos detallados de las actividades turísticas (cascadas, caminatas, etc.).
- **Alojamientos.csv**: Lista de hoteles y sitios de hospedaje.
- **Municipios.csv**: Información sobre los municipios del Caquetá, incluyendo su clima.
- **Personas.csv**: Datos de turistas y operadores.

*Nota: Estos archivos sirven de entrada para el proceso de mapeo a la ontología.*
